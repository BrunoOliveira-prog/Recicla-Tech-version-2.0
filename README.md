## ✨ Versão 2.0 (Atual) - "Eco-Tech Experience"
**Foco:** Experiência do Usuário (UX), Design Profissional e Arquitetura Escalável.
Esta versão elevou o projeto de um protótipo funcional para uma aplicação com "look & feel" de produto de mercado.
### 1. Conceito Visual: "Eco-Tech"
A identidade visual foi totalmente reformulada para unir sustentabilidade com modernidade tecnológica.
- **Paleta de Cores (Emerald & Teal):** Substituímos o verde genérico por tons de Esmeralda e Verde-azulado. O "Teal" traz um toque de inovação tecnológica, fugindo do clichê de sites de reciclagem antigos.
- **Dark Mode & Glassmorphism:** Implementação de temas claro/escuro e efeitos de vidro fosco (`backdrop-blur`) no cabeçalho e cards, criando profundidade e hierarquia visual moderna (similar ao iOS e Windows 11).
### 2. Experiência do Usuário (UX) e Carga Cognitiva
O foco foi reduzir o esforço mental do usuário para realizar tarefas (Lei de Miller).
- **Guia Interativo (Abas):** O conteúdo educativo foi reestruturado em abas (Tabs) - *Básico, Descarte, Ciclo, Legislação, FAQ*. Isso evita a "parede de texto" e permite que o usuário consuma a informação em pedaços digeríveis.
- **Formulários Intuitivos:** Na página de Agendamento, campos relacionados foram agrupados visualmente e enriquecidos com ícones (`lucide-react`) para reconhecimento rápido.
### 3. Arquitetura Frontend
- **Componentização (Shadcn UI):** Adoção de uma biblioteca de componentes baseada em Radix UI para garantir acessibilidade (leitores de tela, navegação por teclado) e consistência.
- **Utility-First (Tailwind CSS):** Estilização feita diretamente nas classes utilitárias, facilitando a manutenção e garantindo a fidelidade ao Design System sem a necessidade de arquivos CSS gigantescos.
